The History of Linux

What started as a student's hobby project — "just a hobby, won't be big and professional" — became the operating system kernel that powers most of the internet, every Android phone, the world's supercomputers, and the cloud.

Origins: Unix and GNU

Linux did not appear from nowhere. In 1969, Ken Thompson and Dennis Ritchie at Bell Labs created Unix, an influential operating system whose ideas — files, processes, pipes and a portable C codebase — shaped everything after it.

In 1983, Richard Stallman launched the GNU Project to build a completely free, Unix-like operating system, and founded the Free Software Foundation in 1985. GNU produced essential tools (GCC compiler, Bash shell, core utilities) and the GPL licence — but its own kernel, Hurd, was not ready.

The missing piece arrived in 1991 from Helsinki, Finland.

Timeline of Linux History

Click a card heading to expand it. Use the filter to jump between eras.

Unix is created at Bell Labs. Its design philosophy influences Linux and almost every modern operating system.

Richard Stallman announces GNU, aiming for a free Unix-like system, and later releases the GNU General Public License (GPL).

Andrew Tanenbaum releases MINIX, a small Unix-like system for teaching. A Finnish student named Linus Torvalds uses it — and wants more.

Linus Torvalds posts to the comp.os.minix newsgroup: "I'm doing a (free) operating system (just a hobby, won't be big and professional like gnu)".

The first Linux kernel, version 0.01 (about 10,000 lines of code), is released on the internet.

Linux is re-licensed under the GNU GPL. GNU tools + the Linux kernel form a complete free operating system, and the first distributions appear.

Slackware and Debian, two of the oldest surviving distributions, are released. Debian's community model later becomes the base for Ubuntu and many others.

Linux kernel 1.0 is released. Red Hat is founded around the same period, bringing commercial support to Linux.

Tux, drawn by Larry Ewing, becomes the official Linux mascot.

IBM, Oracle and other major companies announce Linux support. In 1999 Red Hat's IPO becomes one of the biggest first-day gains in Wall Street history at the time.

Canonical releases Ubuntu, focused on ease of use — "Linux for human beings" — bringing Linux to millions of desktop users.

Torvalds creates Git to manage kernel development. Git goes on to transform how the whole world writes software.

Google's Android, built on the Linux kernel, is announced and the first Android phone ships in 2008. Linux quietly enters billions of pockets.

Docker popularises Linux containers (2013) and Google open-sources Kubernetes (2014). Linux becomes the foundation of modern cloud infrastructure.

By November 2017, all 500 of the world's fastest supercomputers run Linux.

Linux powers most web servers and cloud instances, Android devices, smart TVs, routers, cars, spacecraft — and even Windows, through WSL (Windows Subsystem for Linux).

Key People

Linus Torvalds

Creator of the Linux kernel (1991) and Git (2005). He still leads kernel development today.

Richard Stallman

Founder of the GNU Project and the Free Software Foundation; author of the GPL that Linux is licensed under.

Ken Thompson & Dennis Ritchie

Creators of Unix and the C programming language — the ground Linux was built on.

Famous Distributions

  • Debian (1993) — community-driven, base for Ubuntu.
  • Slackware (1993) — the oldest distribution still maintained.
  • Red Hat / Fedora / CentOS Stream — enterprise Linux.
  • Ubuntu (2004) — popular desktop and server distribution.
  • Arch Linux (2002) — rolling release, do-it-yourself philosophy.
  • Android (2008) — the most widely used Linux-based system in the world.

Linux Today

The Linux kernel now contains over 28 million lines of code and is developed by thousands of contributors from hundreds of companies. It is a textbook example of how open, collaborative development can out-build any single organisation.
